# Customer Personality Analysis 🧠🛍️

This project explores and segments customers based on marketing data, using Python (Pandas, Seaborn, Scikit-Learn) and prepares cloud automation for reporting.

## Goals
- Understand spending behavior
- Create customer segments
- Automate insights reporting to the cloud

## Tools
Python · Pandas · Matplotlib · AWS (S3) · Jupyter · Git · WSL

## Status
✅ Initial EDA complete  
🔜 Clustering and automation in progress
